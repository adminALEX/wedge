# Wedge 1.0 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor Wedge step by step into the public Wedge 1.0: anchored glass panel (A1), Pop & Rise Done (D1) with ⌘Z undo, one-page Settings (S1), the Now · Up Next · Done language, App Intents, G1 icon, and a signed, notarized release.

**Architecture:** A composition root (`AppEnvironment`) builds observable state (`WedgeStore`, `WedgeSettings`) and thin AppKit shells (`StatusItemController`, `PanelController`) around pure SwiftUI views. Every Done goes through `DoneAction`. No notifications, no activation-policy changes, no private selectors. Pure logic (`PanelAnchor`, `InputLimit`, `UndoRoute`, `StatusItemTitle`) is extracted so it can be unit-tested.

**Tech Stack:** Swift 6, SwiftUI + AppKit on macOS 26 (Liquid Glass), Observation, Swift Testing, XCUITest, AVFoundation, ServiceManagement, App Intents, KeyboardShortcuts (only dependency).

**Spec:** [docs/superpowers/specs/2026-11-01-wedge-1.0-redesign-design.md](../specs/2026-11-01-wedge-1.0-redesign-design.md). Read it before starting; section numbers below (§n) refer to it.

## Global Constraints

- **Run on a Mac with Xcode 26+.** Every build and test command is `xcodebuild`; nothing here runs on Linux.
- Deployment target **macOS 26.0**; `MARKETING_VERSION` **1.0**; Swift **6** language mode; `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` (kept); App Sandbox on; hardened runtime on.
- Bundle ID stays `com.xela.wedge`. Logger subsystem = bundle ID (spec §10.5 said `com.wedge`; use the real bundle ID).
- The project uses **file-system synchronized groups**: files created under `wedge/`, `wedgeTests/`, `wedgeUITests/` join their target automatically. Do not edit `project.pbxproj` to add files.
- Only dependency: KeyboardShortcuts. No network entitlement.
- Language: **Now** · **Up Next** · **Done**. Never "one thing", "one task", "pop" (except the sound name "Pop (default)"), "push", "stack", "P0", "Focus", "Today".
- Voice: quiet and plain. No `NSSound.beep()` as feedback; every failure is an inline message using the exact strings in spec §2.
- No `NotificationCenter` for app events, no `DispatchQueue.main.async` focus workarounds, no private selectors, no `NSApp.setActivationPolicy` calls. `LSUIElement` stays `YES`.
- 40-character cap counts **Swift `Character`s** (grapheme clusters).
- No file over ~200 lines. Each task deletes the code it replaces. No data migration: old `wedge.*` defaults keys are ignored.
- Commit trailer on every commit:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```

**Commands** (from the repo root):
- Unit tests: `xcodebuild test -scheme wedge -destination 'platform=macOS' -only-testing:wedgeTests`
- One suite: append `/<SuiteType>`, e.g. `-only-testing:wedgeTests/WedgeStoreTests`
- UI tests: `xcodebuild test -scheme wedge -destination 'platform=macOS' -only-testing:wedgeUITests`
- Build only: `xcodebuild build -scheme wedge -destination 'platform=macOS'`
- "Expected: PASS" means `** TEST SUCCEEDED **` with zero failures.

## Review Focus

1. **Emoji and combined characters at the limit:** "👨‍👩‍👧‍👦" counts as 1 of 40; 40 such characters are accepted and 41 refused. Pinned in Task 2 (`acceptsFortyGraphemeClusters`) and Task 8 (`InputLimitTests`).
2. **Multi-line paste or tabs in item text:** the menu-bar title must stay on one line, so newlines and tabs are collapsed to single spaces before validation. Pinned in Task 2 (`collapsesNewlinesAndTabs`).
3. **Rapid repeated Done (held hotkey, double ⌥-click) mid-animation:** each Done completes exactly one item, in order, and undo restores only the latest. Pinned in Task 4 (`rapidDoneCompletesInOrder`).
4. **Status item has no usable frame (hidden behind the notch, display unplugged while open):** the panel opens at the top-right of the active screen. Pinned in Task 5 (`fallsBackWhenItemOffscreen`).
5. **First launch with no Application Support folder:** the first save creates `Wedge/` and `wedge.json`. Pinned in Task 2 (`saveCreatesMissingDirectory`).
