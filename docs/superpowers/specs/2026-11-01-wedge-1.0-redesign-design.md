# Wedge 1.0 — Redesign (design)

**Date:** 2026-11-01
**Status:** Draft for review
**Supersedes:** product horizon "v1 → v3 only" in [`docs/product/roadmap.md`](../../product/roadmap.md). v1–v3 behaviour is the requirements baseline.
**Mockups (reference):** Wedge Design Directions artifact (panel A1, Done D1, Settings S1, icon G1).

## 1. Product future

| Decision | Value |
|---|---|
| Audience | Public, free, open source (GitHub) |
| Distribution | Developer ID–signed, notarized `.zip`/`.dmg` on GitHub Releases. No Mac App Store. No in-app updater in 1.0. |
| Minimum OS | **macOS 26 Tahoe** (Liquid Glass APIs, no fallbacks). Apple silicon and the last Intel Macs on 26. |
| Version | This redesign ships as **Wedge 1.0**. Internal v1–v3 tags remain history. |
| Scope after 1.0 | **Focused by default.** Bug fixes, OS updates and polish ship freely. A new feature is added only by deliberate decision, with its own short design doc, and only if it fits the core rules (one item Now, order = priority, menu-bar only, local only). |
| Users today | None. No data migration, no compatibility code, old `wedge.*` defaults keys are dropped. |

Unchanged core (from v1–v3): menu-bar only (no Dock, no Cmd-Tab), the Now item in the bar, ordered list where position is priority, adds go to the bottom of Up Next, 40-character cap, local persistence, Done with sound, global hotkeys, open at login. Still out of product: sync, accounts, Dock mode, confetti, priority fields.

## 2. Product language

**Nouns:** **Now** (the top item) · **Up Next** (everything below) · **Done**. All title case as labels.

**Why not "one thing":** *One Thing* (and its sister app *One Task*) are existing Mac menu-bar apps by Sindre Sorhus. Wedge's public language must not echo a competitor's name. Also avoid: Focus, Spotlight (macOS features), Today, On Deck, Priority, Pinned. Internal code names follow the UI noun (`NowHeader`, not `OneThingHeader`).

**Voice:** quiet and plain, like Apple's own utilities. No praise, no emoji, no exclamation marks. Motion and sound carry the emotion.

| Where | Copy |
|---|---|
| Add field, empty list | What are you on now? |
| Add field, otherwise | Add to Up Next… |
| Section labels | Now · Up Next |
| Menu | Done · Undo Done · Settings… · Quit Wedge |
| Undo hint | Undo Done ⌘Z |
| Shortcut names | Show Wedge · Done |
| Settings rows | Bold · Color (Automatic / Custom) · Play sound · Sound · Open at login |
| Errors | 40 characters max · Can't be empty · Couldn't save. Your latest changes may be lost. · That sound is longer than 3 seconds. · Couldn't read that sound file. · Couldn't change this. Check System Settings › General › Login Items. |

Rules:
- "pop" is an internal name only. The UI says **Done sound** / **Pop (default)** only as the bundled sound's name.
- No OS-version caveats or developer notes in UI copy.
- Every failure is a short inline message. No `NSSound.beep()` as feedback.
- All strings live in a **String Catalog**; `WedgeCopy` remains the single typed entry point.

## 3. Design language

**Platform-native first.** System font (SF Pro), system materials (Liquid Glass), system controls, system accent. Wedge adds exactly one signature: the Done moment.

### 3.1 Panel (A1, anchored)
- Borderless, **non-activating** glass panel anchored under the status item, 320 pt wide, radius matching macOS 26 menu-bar extras. Opens on the display whose menu bar was clicked.
- No title bar, no window title text.
- Layout, top to bottom:
  1. **Now:** small **Now** label (same style as Up Next), then the header row: a ring (the Done control) and the Now item, semibold, larger than rows.
  2. Hairline separator.
  3. **Up Next** label, then numbered rows (2, 3, 4…). Rows drag by their whole body; no grip dots.
  4. **Add field** (rounded, subtle fill), with a counter `n/40` shown from 30 characters.
  5. **Hint row:** `⌘↩ Done` · `⌘, Settings` (always shown).
- Height fits content up to about 8 rows, then the list scrolls.
- Empty list: Now section absent; add field shows "What are you on now?".
- Menu-bar item stays highlighted while the panel is open.

### 3.2 Done moment (D1, pop & rise)
- Ring fills with the system green and checks → title swells ~6% and pops out (scale down + fade) → next row rises into the header slot while the rows below shift up → menu-bar title swaps with a small bump.
- Spring timing, ~450 ms total. Paired with the Done sound.
- "Undo Done ⌘Z" hint fades in for ~4 s.
- With the panel closed: menu-bar swap + bump + sound only.
- **Reduce Motion:** instant swap + sound.
- Identical for every entry point (ring, ⌘↩, ⌥-click, menu, hotkey).

### 3.3 Settings (S1, one page)
- Native SwiftUI `Settings` scene, grouped `Form`, single page, no tabs.
- Groups in order: **Menu Bar** (live `MenuBarPreview`, Bold, Color Automatic/Custom + picker) · **Done** (Play sound, Sound: name + Preview + Choose… + Use Default when custom) · **Keyboard** (Show Wedge, Done recorders, Reset) · **Open at login** · About row (`Wedge 1.0` · GitHub link).
- Inline error text under the row that failed.
- If Settings ever outgrows one screen, move to toolbar tabs (General · Menu Bar · Keyboard). Not needed for 1.0.

### 3.4 Icon (G1)
- **Concept:** a wedge holding up a single bar, the Now item. "The top piece."
- **App icon:** graphite background; the wedge is a smoky glass layer; the bar is the only bright element (white glass). Built in **Icon Composer** as a layered macOS 26 icon with default, dark and tinted appearances.
- **Menu-bar glyph:** same silhouette as a 16 pt **template** image (custom symbol), shown only when the list is empty. Replaces SF Symbol `leaf`.
- The Done "rise" and the icon's raised bar are the same gesture.

## 4. Architecture

Approach: **step-by-step refactor** of the existing codebase (§5). Target structure:

| Unit | Responsibility | Replaces |
|---|---|---|
| `WedgeStore` (`@Observable`, main actor) | List state and all mutations. Persists after every mutation through an injected `WedgePersisting`. Holds `lastDone` for undo. Exposes a `saveError` state. | `onChange` callbacks; `try?` saves |
| `WedgeSettings` (`@Observable`) | Bold, color, sound on/off, custom sound file name; backed by `UserDefaults` | `MenuBarAppearance` and `PopSoundPreferences` static enums + notifications |
| `CustomSoundStore` | Validate (type, ≤3 s) and install/remove the custom sound in Application Support | file-handling half of `PopSoundPreferences` |
| `DonePlayer` (protocol) / `PopSoundPlayer` | Play the bundled or custom sound; preloaded | `PopSoundPlayer` (kept, behind a protocol) |
| `DoneAction` | The single Done path: complete → sound → publish a `doneEvent` the views animate on → arm undo | `performDone()` + `wedgeDidPop` |
| `StatusItemController` (AppKit) | NSStatusItem only: render title/glyph from store + settings via observation, route left / ⌥ / right clicks, build the menu | 287-line controller |
| `PanelController` + `WedgePanel` (NSPanel subclass) | Create once, anchor under the item, show/hide, close on Esc / resign key / outside click | titled centered `NSPanel`, activation-policy flips |
| `PanelAnchor` (pure) | Compute panel frame from status-item frame + screen visible frame (clamped) | `centerPanelOnScreen` |
| `HotkeyController` | KeyboardShortcuts names, defaults, handlers | hotkey code inside the controller |
| `LaunchAtLoginService` | Unchanged (SMAppService) | — |
| Views | `PanelView` → `NowHeader`, `UpNextList`, `AddField`, `UndoHint`; `SettingsView` → `MenuBarPreview` | `PopoverContentView` |
| `WedgeCopy` | Typed accessors over the String Catalog | string constants |

**Rules**
- No `NotificationCenter` for app events; observe state.
- No `DispatchQueue.main.async` focus workarounds; use `@FocusState` and `defaultFocus`.
- No private selectors. Settings opens via SwiftUI `openSettings`.
- The app never changes its activation policy; it stays `.accessory` (`LSUIElement`).
- One file per unit; no file over ~200 lines.

## 5. Refactor order

Each step builds, passes all tests, and deletes the code it replaces before commit.

1. **Baseline:** deployment target macOS 26, `MARKETING_VERSION` 1.0, Swift 6 language mode, hardened runtime on, remove macOS 15 copy caveats. Tests green.
2. **Core state:** `WedgeStore` self-persists + undo + `saveError`; `WedgeSettings`; `CustomSoundStore`. Delete app notifications.
3. **Actions:** `DoneAction`, `HotkeyController`; slim `StatusItemController` to the item only.
4. **Panel shell:** `WedgePanel` (borderless, non-activating, glass), `PanelAnchor`, close behaviours; remove activation-policy code and `showSettingsWindow:`; Settings via `openSettings`.
5. **Panel content (A1):** `NowHeader` (ring = Done), `UpNextList` (whole-row drag, click to edit, keyboard), `AddField` (counter, inline errors), save-error banner.
6. **Done moment (D1):** animation, menu-bar bump, `UndoHint`, Reduce Motion.
7. **Settings (S1):** grouped page, `MenuBarPreview`, about row, inline errors.
8. **Language, icon & docs:** String Catalog + `WedgeCopy` pass; G1 app icon (Icon Composer) and template glyph; rewrite `docs/product/overview.md` and `roadmap.md` for "Wedge 1.0, focused by default" (including the feature process from §1); retire `phases/v1–v3` to history; update `.cursor/rules/`.
9. **Release:** Developer ID signing, notarization + stapling, GitHub Release, README for new users (what it is, install, shortcuts, screenshot).

## 6. Behaviour

### Menu-bar item
| Input | Result |
|---|---|
| Left click | Toggle panel |
| ⌥-click | Done (empty list: open panel) |
| Right click | Menu: Done (shows shortcut, disabled when empty) · Undo Done (only when available) · Settings… · Quit Wedge |
| Display | Empty → G1 template glyph; otherwise the Now item in the chosen bold/color |

### Panel
- Opens with the add field focused. Closes on ⌃⌥W, Esc (when not editing), or click outside.

| Key | Action |
|---|---|
| ↑ / ↓ | Move selection; ↑ from the add field enters the list |
| ↩ on a row | Edit the row |
| ⌘↩ | Done |
| ⌫ | Delete selected row (no confirmation) |
| ⌥⌘↑ / ⌥⌘↓ | Move selected row up/down (keyboard and VoiceOver reorder) |
| ⌘Z | Undo typing if a field has unsaved typing; otherwise Undo Done |
| ⌘, | Settings |
| Esc | Cancel edit; otherwise close panel |

### Editing and adding
- Click row text to edit. ↩ saves, Esc cancels, click elsewhere saves.
- Add appends to the bottom; the first item becomes Now.
- Input stops at 40 characters; counter from 30; an over-long paste is refused with "40 characters max". Empty edit → "Can't be empty", text restored.
- Dragging a row to the top makes it Now (no Done animation).

### Undo
- ⌘Z (or menu Undo Done) restores the last Done item to the top.
- Available until the next list mutation. A new Done replaces it. Deletes are not undoable.

### Errors
- Save failure → panel banner "Couldn't save. Your latest changes may be lost." (cleared on next successful save).
- Custom sound invalid/too long → inline under the Sound row; previous sound kept.
- Login item failure → inline under the toggle; toggle reflects real state.

### Accessibility
- Follows light/dark, Reduce Motion, Reduce Transparency, Increase Contrast.
- VoiceOver: Now header "Now, ‹title›"; ring "Done, ‹title›"; rows "‹n› of ‹count›, ‹title›"; move up/down as accessibility actions; panel announced as "Wedge".

## 7. Standards & performance

**Code standards**
- Swift 6 language mode, complete concurrency checking, `MainActor` default isolation (kept).
- App Sandbox on (kept); hardened runtime on.
- `swift-format` config in repo; formatting checked in CI.
- GitHub Actions: build + unit tests + UI smoke tests on every push and PR (macOS runner with Xcode 26+).
- Dependencies: KeyboardShortcuts only.

**Performance budgets** (verified with Instruments before release)
| Metric | Budget |
|---|---|
| Idle CPU | 0% — no timers or polling; status item redraws only on observed change |
| Idle memory | ≤ 50 MB resident |
| Click → panel visible | Within one frame; panel created once and reused |
| Done animation | No dropped frames at 120 Hz (SwiftUI Instruments template) |
| Sound latency | Preloaded player; no audible delay after Done |
| Launch → item in menu bar | < 300 ms on Apple silicon |

## 8. Testing

**Unit (Swift Testing), test-first in steps 2–7**
- `WedgeStore`: add/edit/delete/move, 40-char cap, empty text, persists after each mutation (fake persister), save failure sets `saveError`.
- Undo: restores to top; available only until next mutation; new Done replaces it.
- `WedgeSettings`: defaults and round-trip. `CustomSoundStore`: type and duration validation (existing fixtures).
- `DoneAction`: completes, plays via protocol (silent in tests), emits event; no-op when empty.
- Pure logic: `PanelAnchor` (clamping, multi-display), ⌘Z routing rule, counter visibility and paste refusal.
- `WedgeCopy`: every key resolves to a non-empty string.

**UI smoke (XCUITest)** — replaces the skipped placeholder. A test-only launch argument opens the panel with an in-memory store:
- add → edit → ⌥⌘↓ reorder → Done → ⌘Z
- ⌘, opens Settings

## 9. Non-goals for 1.0

These are today's decisions, not permanent bans; any of them can be revisited through the feature process in §1.

Sync / iCloud / accounts · Dock mode · confetti · priority fields · tags or multiple lists · in-app updater · Mac App Store build · undo for anything other than Done · truncation of long titles (40-char cap stays).
