# Wedge v3.0.2 — Empty icon + panel selection (design)

**Date:** 2026-09-07  
**Status:** Approved for planning  
**Product:** patch on shipped v3 — [`docs/product/phases/v3.md`](../../product/phases/v3.md)

## Goal

Small polish release: empty menu-bar icon feels free/calm (quiet brand), and panel list selection shows a real system filled highlight again. No new features.

## Empty menu-bar icon

| Rule | Behavior |
|------|----------|
| When | List empty → status item **icon only** (unchanged product rule) |
| What | Replace SF Symbol `circle.fill` with **`leaf`** (template) |
| Fallbacks (smoke only) | If `leaf` feels wrong in the bar: `triangle`, then `circle.dotted` |
| Constraints | SF Symbol only; `isTemplate = true`; keep `WedgeCopy.statusItemAccessibility`; no custom asset |

Intent: **free / clear** + **quiet brand**, not “add” or “done.”

## Panel list selection

| Rule | Behavior |
|------|----------|
| Selection | Restore **system** filled selection (accent / secondary) via native `List(selection:)` |
| Borders | Opportunistic only — take softer separators/edges if the native list style fix brings them; no bespoke border redesign |
| Non-goals | Custom Notion-style selection pills, full panel restyle, new list chrome |

**Root cause (current):** `PopoverContentView` uses `.listStyle(.plain)` + `.scrollContentBackground(.hidden)`, which commonly drops the filled selection background.

**Fix direction (ponytail):** Prefer deleting/changing those modifiers so AppKit draws selection again — fewest lines, no painted `listRowBackground`.

## Non-goals

Custom icon art, Dock mode, cloud, confetti, selection redesign beyond system fill, panel layout/spacing rewrite.

## Success

- Empty list → menu bar shows template `leaf` (or agreed fallback), not solid circle.
- Non-empty → title only (unchanged).
- Keyboard/list selection shows a **filled** row highlight.
- No new Settings, hotkeys, or copy strings required (unless accessibility description needs a one-word tweak — prefer leave as-is).
- Tag **`v3.0.2`** when shipped; phase doc notes the patch.
