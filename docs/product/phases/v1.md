# Wedge v1 — Core

**Status:** Implemented — pending manual acceptance  
**Goal:** A daily-driver menu-bar focus list with a satisfying Done/pop.

## In scope

### Product
- macOS **menu-bar only** (no Dock, no Cmd-Tab app window).
- Menu bar shows the **one thing** as title only (no circle icon), or **icon only** when empty.
- Ordered list: top = one thing; below = **Up next**; drag to reorder; position = priority.
- **Launch at login.**
- Local **persistence** across quit/reboot.
- **Max 40 characters** per item. Enforce the limit (block/reject input over 40). **No truncation logic** (no ellipsis system for longer text).

### Panel (left click)
- Compact **floating panel** on left click, **centered on screen** (not a transient menu-bar popover — so typing/editing stays reliable). Shown whether the list is empty or not. Add field is focused when the panel opens.
- Window title bar shows **Wedge** (no in-content app title; no panel **Done** button).
- Toggle: click the status item again, or close the panel’s window chrome.
- **Single list:** top row visually emphasized as the one thing; same list for drag.
- Reorder: native list drag with a **Notion-style 6-dot grip** on each row (always visible affordance).
- Always-visible add field:
  - Empty list: placeholder like “What’s your one thing?” — first item becomes the one thing.
  - Non-empty: “Add to up next…” — **always appends to the bottom**.
- Inline edit; delete via ⌫ / context menu (not swipe-as-primary).

### Done / pop (emotional core)
- Removes the one thing; next item becomes the one thing; empty → icon only.
- Satisfaction: **panel animation + menu bar title update** together, plus a **satisfying pop sound** (bundled `Sounds/pop-sound.mp3`).
- Paths:
  - **⌘↩** while the panel is key
  - **⌥ + click** on status item when a one thing exists (power-user fast clear)
  - **Right-click menu → Done** (native menu; also Settings…, Quit)
- If there is no one thing, Done shortcuts no-op / disabled (plain click still opens the panel).
- **Not in v1:** Force-click / hard-click Done (⌥-click is enough); no Done button in the panel chrome.

### Settings (minimal)
- Open with **⌘,** while the panel is open, or **right-click status item → Settings…** — native SwiftUI `Settings` scene.
- While the panel (or Settings) is open, Wedge briefly uses normal activation so the app menu / ⌘, work; otherwise it stays menu-bar accessory (no Dock).
- Adjust **menu-bar one-thing** text: **bold**, and **color** (Automatic = system label color, or a custom color). Persisted. More settings later (see v3).

### Language
- UI: **one thing**, **Up next**, **Done**. Not push/pop/stack/P0.

## Out of scope (v1)

- Global hotkeys (→ v2)
- Full Preferences (sound picker, login toggle UI, hotkey remap → v3)
- Character limits above 40 / truncation / ellipsis (discuss later; not v1)
- Cloud sync, accounts, Dock mode, confetti

## Success criteria

- User can add items, drag priority (grip affordance), see the one thing in the bar, Done with pop+sound, and get the list back after reboot.
- Launch at login works.
- Items cannot exceed 40 characters.
- Settings open via ⌘, (panel open) and status-item **Settings…**.
