# Wedge v1 — Core

**Status:** Implemented — ready for acceptance  
**Goal:** A daily-driver menu-bar focus list with a satisfying Done/pop.

## In scope

### Product
- macOS **menu-bar only** (no Dock, no Cmd-Tab app window).
- Menu bar shows the **one thing** (list index 0), or **icon only** when empty.
- Ordered list: top = one thing; below = **Up next**; drag to reorder; position = priority.
- **Launch at login.**
- Local **persistence** across quit/reboot.
- **Max 40 characters** per item. Enforce the limit (block/reject input over 40). **No truncation logic** (no ellipsis system for longer text).

### Popover
- Compact popover on left click.
- **Single list:** top row visually emphasized as the one thing; same list for drag.
- Fixed header **Done** above the list.
- Always-visible add field:
  - Empty list: placeholder like “What’s your one thing?” — first item becomes the one thing.
  - Non-empty: “Add to up next…” — **always appends to the bottom**.
- Inline edit; delete via ⌫ / context menu (not swipe-as-primary).

### Done / pop (emotional core)
- Removes the one thing; next item becomes the one thing; empty → icon only.
- Satisfaction: **popover animation + menu bar title update** together, plus a **satisfying pop sound**.
- Paths:
  - Done in popover header
  - **⌘↩** while popover is open
  - **Force click** on status item
  - **⌥ + left click** on status item
  - **Right-click menu → Done** (native menu; also Quit, etc.)
- If there is no one thing, Done shortcuts no-op / disabled.

### Language
- UI: **one thing**, **Up next**, **Done**. Not push/pop/stack/P0.

## Out of scope (v1)

- Global hotkeys (→ v2)
- Preferences / Settings UI (→ v3)
- Hotkey remapping (→ v3)
- Character limits above 40 / truncation / ellipsis (discuss later; not v1)
- Cloud sync, accounts, Dock mode, confetti

## Success criteria

- User can add items, drag priority, see the one thing in the bar, Done with pop+sound, and get the list back after reboot.
- Launch at login works.
- Items cannot exceed 40 characters.
