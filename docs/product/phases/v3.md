# Wedge v3 — Control

**Status:** Shipped  
**Goal:** Expand Settings beyond appearance (v1) and hotkey remapping (v2).

## Already shipped (do not rebuild)

### v1
- Settings (**⌘,** and status-item **Settings…**) with **menu bar text bold** and **color** (automatic system label, or custom)

### v2
- Global hotkeys (Toggle panel, Done) with **defaults + remapping** in Settings — see [v2.md](v2.md)

## In scope (shipped)

Additions to Settings:

1. **Pop sound** — **on/off** toggle (default on; Done is fully silent when off). Optional **custom sound file** via Choose… (default remains bundled `pop-sound.mp3`; Use default clears custom). Preview button. Custom file copied into Application Support (sandbox-friendly). Supported types: AIFF, WAV, MP3, M4A, CAF. **Max duration 3 seconds** (longer files are rejected).
2. **Launch at login** — user-visible toggle in Settings (General section). v1 still enables on first run; v3 exposes register/unregister via `SMAppService`.

Also: status-item context menu shows the remappable **Done** shortcut; UI copy lives in `WedgeCopy`.
