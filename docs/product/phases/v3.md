# Wedge v3 — Control

**Status:** Planned (after v2)  
**Goal:** Expand Settings beyond the minimal menu-bar look controls shipped in v1.

## Already in v1 (do not rebuild)

- Settings (**⌘,** and status-item **Settings…**) with **menu bar text bold** and **color** (automatic system label, or custom)

## In scope (v3 expansion)

Add to Settings:

1. **Pop sound** — on/off and/or choose among a small set of sounds  
2. **Launch at login** — user-visible control (v1 enables it silently; v3 exposes/edits cleanly)  
3. **Hotkey remapping** — change the global shortcuts introduced in v2  

## Explicitly not in v3 (and not in the product)

Do **not** add:

- Dock icon toggle / Dock mode  
- “Make this my one thing” / steal-focus-on-add modes (adds stay bottom of Up next)  
- Cloud sync, iCloud, accounts  
- Confetti or celebration gimmicks  
- A v4 roadmap or “platform” expansion

- [v1.md](v1.md) for core behavior, login foundation, and minimal Settings shell  
- [v2.md](v2.md) for global hotkeys to remap
