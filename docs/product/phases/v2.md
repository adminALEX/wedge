# Wedge v2 — Speed

**Status:** Implemented — pending manual acceptance  
**Goal:** Power users move faster without opening Preferences for day-to-day actions.

## In scope

### Global hotkeys (system-wide)

Defaults (Option **A**):

| Action | Default |
|--------|---------|
| Toggle panel | **⌃⌥W** |
| Done (pop) when a one thing exists | **⌃⌥D** |

- No separate global “focus add field” hotkey — opening the panel already focuses the add field (v1).
- Implemented via **KeyboardShortcuts** (Carbon `RegisterEventHotKey`) — **no Accessibility** permission prompt for the defaults.
- Done no-ops (no sound) when the list has no one thing.
- Secure Input (e.g. password fields): OS suppresses global hotkeys — expected.

### Remapping in Settings (v2)

- Settings **Keyboard shortcuts** section with recorders for **Toggle panel** and **Done**.
- Persist remapped chords locally; survive quit/relaunch.
- **Reset to defaults** restores ⌃⌥W / ⌃⌥D.
- Prefer remaps that include **Control or Command** (Option/Shift-only can fail on some macOS 15.x versions).

### Panel keyboard (when panel is key)

- Move selection up/down through the list (`List(selection:)`).
- ⌫ deletes the selected row (when not editing a field / add field).
- Keep **⌘↩** = Done.
- Tap row text still enters inline edit.

## Out of scope (v2)

- Sound picker / sound on-off UI (→ v3)
- Launch-at-login toggle in Settings (→ v3)
- Truncation / raising the 40-char limit — **not designed**; discuss and update this doc before implementing
- Cloud sync, Dock mode, confetti, “add as one thing”
- Extra global hotkeys beyond Toggle + Done
