# Wedge v2 — Speed

**Status:** Planned (next — v1 shipped)  
**Goal:** Power users move faster without opening Preferences.

## In scope

- **Global hotkeys** (system-wide), at minimum:
  - Open / toggle panel
  - Done (pop) when a one thing exists
  - Optionally focus the add field
- Denser **panel keyboard** use when open: move selection, ⌫ delete selected row, keep ⌘↩ = Done.
- Default hotkey chords chosen for power users; remapping waits for **v3**.

## Out of scope (v2)

- Preferences window (→ v3)
- Hotkey remapping UI (→ v3)
- Sound picker UI (→ v3) — v1 ships a default pop sound
- Truncation / raising the 40-char limit — **not designed**; discuss and update this doc before implementing
- Cloud sync, Dock mode, confetti, “add as one thing”

## Depends on

- [v1.md](v1.md) core loop shipping and stable enough to shortcut.
