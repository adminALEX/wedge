# Wedge v2 — Speed

**Status:** Planned (next — v1 shipped)  
**Goal:** Power users move faster without opening Preferences for day-to-day actions.

## In scope

### Global hotkeys (system-wide)

Defaults (Option **A**):

| Action | Default |
|--------|---------|
| Toggle panel | **⌃⌥W** |
| Done (pop) when a one thing exists | **⌃⌥D** |

- No separate global “focus add field” hotkey — opening the panel already focuses the add field (v1).
- Hotkeys require macOS **Accessibility** permission; surface a clear path to enable it when registration fails or is denied.
- Done no-ops (no sound) when the list has no one thing.

### Remapping in Settings (v2)

- Settings gains a **Hotkeys** section with recorders for **Toggle panel** and **Done**.
- Persist remapped chords locally; survive quit/relaunch.
- Provide a **Reset to defaults** control for the two hotkeys.
- Remapping stays in this native Settings scene (no separate Preferences window).

### Panel keyboard (when panel is key)

- Move selection up/down through the list.
- ⌫ deletes the selected row (when not editing a field).
- Keep **⌘↩** = Done.

## Out of scope (v2)

- Sound picker / sound on-off UI (→ v3)
- Launch-at-login toggle in Settings (→ v3)
- Truncation / raising the 40-char limit — **not designed**; discuss and update this doc before implementing
- Cloud sync, Dock mode, confetti, “add as one thing”
- Extra global hotkeys beyond Toggle + Done
