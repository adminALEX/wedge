Wedge can now update itself.

## What's changed

- **Check for Updates.** Settings has a Check for Updates… button. When a newer version is out, Wedge downloads it, installs it and reopens, so you don't need to download it from the site again.
- **Only when you ask.** Wedge connects to GitHub only when you click Check for Updates. It never checks in the background.

This is the last version you need to download by hand. From here on, use Check for Updates.

## Install

1. Download **Wedge-{{VERSION}}.dmg** below and open it.
2. Drag **Wedge** onto the **Applications** folder.
3. Open Wedge from Applications.

### The first time you open it

This build is not yet signed with an Apple Developer ID, so macOS blocks it the first time:

1. When macOS says it can't verify Wedge, click **Done**.
2. Open **System Settings › Privacy & Security** and scroll down to **Security**.
3. Next to "Wedge was blocked to protect your Mac", click **Open Anyway** and confirm.

You only need to do this once.
